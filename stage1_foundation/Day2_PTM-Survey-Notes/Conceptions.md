# 1.AE和AR
AutoEncoding（AE）和 AutoRegressive（AR）是两种常见的预训练方式。AE 的代表是 BERT，它会把句子中的一部分词遮住（Mask），再利用上下文同时预测被遮住的内容，因此能够看到前后文信息，适合理解类任务。AR 的代表是 GPT，它按照“从左到右”的方式，一个词一个词地预测下一个词，只能看到前面的内容，更适合文本生成任务。

# 2.Encoder-AE
Encoder-AE结构是目前最经典的预训练模型结构之一，代表模型是 BERT。它基于单个 Transformer Encoder，并采用 AE（AutoEncoding）方式训练：随机遮住句子中的部分词，再利用上下文去预测这些被 Mask 的词。由于模型在预测时能够同时看到前后文，因此属于“双向语言模型”。这种结构特别擅长文本理解任务，例如分类、阅读理解、情感分析等，但因为它不是按顺序生成文本，所以在文本生成任务上的效果相对较弱。

# 3.Decoder-AR
Decoder-AR结构是典型的自回归预训练结构，代表模型是 GPT 系列。它基于单个 Transformer Decoder，并采用 AR（AutoRegressive）方式训练，即按照“从左到右”的顺序逐个预测下一个词。模型在生成当前词时，只能看到前面的内容，不能看到后面的词，因此属于“单向语言模型”。这种结构非常适合文本生成任务，例如对话、写作和代码生成，因为它天然符合人类逐词生成文本的过程。但由于无法同时利用前后文信息，所以在阅读理解等语言理解类任务上的效果通常不如 Encoder-AE 结构。

# 4.Encoder-Decoder
Encoder-Decoder结构结合了 Encoder-AE 和 Decoder-AR 两种结构的优点。其中，Encoder 部分采用双向语言模型，负责充分理解输入内容；Decoder 部分采用自回归方式，从左到右逐步生成文本，并且还能通过 Attention 读取 Encoder 编码后的信息。因此，这种结构既擅长文本理解，也擅长文本生成，能够统一处理翻译、摘要、问答等多种 NLP 任务。目前它被认为是综合能力最强的结构之一，但由于同时使用了 Encoder 和 Decoder 两套 Transformer，参数量和计算量也明显更大。

# 5.Prefix LM 
Prefix LM可以理解为“轻量版 Encoder-Decoder”。它不像标准 Encoder-Decoder 那样使用两个独立的 Transformer，而是在同一个 Transformer 里通过 Attention Mask 把输入分成两部分：前半部分像 Encoder 一样双向理解文本，后半部分像 Decoder 一样从左到右生成文本。因此，它既能做理解任务，也能做生成任务，代表思路来自 UniLM，T5 论文中称其为 Prefix LM。它的优点是结构更轻、参数更少；缺点是整体效果通常弱于标准 Encoder-Decoder，尤其是在语言理解任务上差距更明显，但在生成任务上表现仍然不错。

# 6.PLM
Permuted Language Model（PLM）是 XLNet 提出的预训练方式，本质上是一种“看起来像 AR，实际上又结合了 AE 思想”的结构。它会随机打乱句子中单词的预测顺序，再按照新的顺序逐步预测单词，因此既保留了自回归生成的特点，又能利用更丰富的上下文信息。相比 BERT，PLM 不再显式使用 Mask 标记，而是通过 Attention Mask 在内部控制可见范围，使预训练与下游任务更一致。不过从后续实验来看，PLM 在理解任务上通常不如 Encoder-AE，在生成任务上又弱于 Decoder-AR，整体属于“两边都能做，但都不是最强”的结构。

# 7.总结
真正让预训练模型性能大幅提升的因素，其实主要只有四个。第一是更多、更高质量的预训练数据；第二是更大的模型容量，也就是更多参数、更深的 Transformer；第三是更充分的训练，例如更大的 Batch Size 和更多训练步数；第四是更有难度、更有效的预训练任务，例如 Span Mask 和 SOP 等。作者认为，目前很多强模型（如 RoBERTa、T5、GPT-3）本质上都在沿着“大数据 + 大模型 + 长训练”的方向发展，而真正拉开差距的关键，很可能还是数据规模和模型规模。

# 8.ELECTRA 
ELECTRA是一种更高效的预训练方法。相比 BERT 只对被 Mask 的少量单词进行预测，ELECTRA 会先用一个小生成器替换句子中的部分词，再让大判别器判断每个词是否被“篡改”过。这样模型中的所有单词都能参与训练，而不只是 15% 的 Mask 词，因此学习效率更高。在相同数据量和模型规模下，ELECTRA 往往能比传统 MLM 方法学得更快、更充分。

# 9. 百度 ERNIE 和清华 ERNIE
除了让模型从普通文本里“自己学习知识”，还能主动把已有的结构化知识（比如知识图谱、实体关系、专业词典）喂给模型。代表性的两种思路分别来自百度 ERNIE 和清华 ERNIE。百度 ERNIE 更偏向“强化 Mask”，会专门 Mask 掉实体或短语，逼模型重点学习这些知识；清华 ERNIE 则会把外部知识库中的实体关系直接融合进模型中，让模型同时学习文本信息和结构化知识。
如果数据规模和模型能力足够强，大模型理论上可以直接从海量文本中学会这些知识，但在当前阶段，显式引入结构化知识，尤其是冷门领域知识，仍然很有价值。

# 10.双流交互模型
双流交互模型是一种典型的多模态预训练结构，代表模型包括 LXMERT 和 ViLBERT。它会分别使用两个独立的编码器：一个处理文本，一个处理图片。文本侧通过 Transformer 学习词语之间的关系；图片侧则先利用 Faster-RCNN 检测图片中的物体和位置，再通过 Transformer 学习图像区域之间的关系。最后，模型再通过额外的跨模态 Transformer 将文本和图片信息融合，从而学习“文字和图像之间的对应关系”。训练时，模型不仅要完成文本预测和图片预测任务，还需要判断文本和图片是否匹配，以增强跨模态语义理解能力。

# 11.单流交互模型
单流交互模型是一种更简洁的多模态预训练结构，代表模型包括 UNITER、VisualBERT 和 Unicoder-VL。与双流模型分别处理文本和图片不同，单流模型只使用一个 Transformer，把图片区域特征和文本单词直接拼接后一起输入模型，让同一个 Transformer 同时学习文本关系、图像关系以及图文之间的语义对应关系。经过这种多模态预训练后，模型能够自动建立“词语—图像区域”的语义映射，例如看到“苹果”这个词时，会自动关注图片中对应的苹果区域。相比双流结构，单流模型参数更少、结构更简单，而且能更早融合不同模态的信息，因此被认为更有潜力。

# 12.灾难遗忘
灾难遗忘（Catastrophic Forgetting）指的是：模型在学习新任务或新领域知识时，把原来已经学会的通用知识“冲掉了”。比如一个通用 BERT 原本学会了大量互联网语言知识，但如果后续只用医学文本继续预训练，模型参数会逐渐偏向医学领域，导致原本的通用语言能力下降。这就像一个人长期只刷某一科题目，最后其它科目的知识慢慢忘掉一样。因此，在领域预训练中，如何既学习新领域知识，又尽量保留原来的通用能力，是一个非常重要的问题。

# 13.四阶段训练框架
第一阶段是通用预训练，用海量通用数据训练一个具备广泛语言能力的大模型；第二阶段是领域预训练，在通用模型基础上继续用医学、计算机、电商等领域数据训练，让模型适应特定领域；第三阶段是任务预训练（TAPT），再利用当前任务自身的数据继续做无监督预训练，让模型进一步贴近具体任务分布；最后才是传统的监督微调（Fine-tuning）。整个思路本质上是“逐层适配”：先学通用知识，再学领域知识，最后学习具体任务特点，从而不断提升模型效果。
